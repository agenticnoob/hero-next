# AXMORF 品牌原文

正式品牌：AXMORF。中文名：易狸；释义尚未提供，暂不添加。

Tagline: Change until the axioms morph.

中文：持续改变，直到公理随之重塑。

AXMORF = AXiom + MORF —— 先确立可以验证的规则，再用迭代证明它们可以被更好的规则取代。

一句话介绍（中）：AXMORF，面向 AI 应用的独立构建者，与 Agent 一起把想法做成可运行、可验证的作品。

一句话介绍（英）：AXMORF — an agent-first independent builder turning ideas into software that runs and can be verified.

名字解释英文译文（待审核）：AXMORF = AXiom + MORF — First establish rules that can be verified, then use iteration to prove that they can be replaced by better rules.
